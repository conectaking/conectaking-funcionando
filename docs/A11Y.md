# A11y — baseline

## Checklist rápido

- [ ] Labels associados a inputs (login, conta, portaria)
- [ ] Focus visível em botões/links
- [ ] Contraste texto/fundo WCAG AA
- [ ] `aria-live` em feedback de check-in (portaria)
- [ ] Skip link “Ir para conteúdo” em páginas longas
- [ ] Imagens com `alt` (ou `alt=""` decorativas)

## Prioridade de páginas

1. `/login`, `/registro`, `/conta`
2. Portaria pública
3. Cartão público
4. Dashboard (iterativo)
